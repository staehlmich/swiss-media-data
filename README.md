# Swiss Media Data

Kanonischer Datensatz mit strukturierten Informationen zu Schweizer Medien.

## Inhalt

`data/media.json` enthält unter anderem folgende Angaben zu den erfassten Medien:

- Name und Unternehmen
- Adresse und Ort
- Kanton
- Geografische Koordinaten
- Sprache
- Medientyp
- Website
- Format
- Themen
- Quelle der Angaben

## Zweck

Der Datensatz soll eine strukturierte und wiederverwendbare Datengrundlage für Recherchen, Analysen und Anwendungen zur Schweizer Medienlandschaft bieten.

Mögliche Anwendungen sind beispielsweise:

- interaktive Visualisierungen und Medienkarten
- journalistische Recherchen
- Analysen von Medienangeboten und Medienunternehmen
- Untersuchungen zu technischen Eigenschaften von Medienwebsites

Der Datensatz soll auch anderen Journalistinnen und Journalisten sowie weiteren Interessierten zur Verfügung stehen, die ihn für eigene Recherchen oder Projekte nutzen möchten.

## Datenpflege

Die Medienliste wird laufend erweitert und aktualisiert. Änderungen an den grundlegenden Angaben zu einem Medium werden in diesem Repository vorgenommen.

Die einzelnen Einträge enthalten eine `source_url`, über die die Herkunft der jeweiligen Angaben nachvollzogen werden kann.

## Status

Der Datensatz befindet sich in Entwicklung und erhebt keinen Anspruch auf Vollständigkeit.
